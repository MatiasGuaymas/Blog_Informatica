# Sources

Raw inputs that the documentation and the site content are based on, kept so
that a later reader can check where a fact came from.

## What goes here

- Official material as received: a study plan page, a calendar resolution, a
  faculty announcement.
- Samples of external data used to document its shape, such as a response of
  the UNLP notice board API.
- Notes and research gathered while planning an epic or a feature.

## Rules

- Name files `YYYY-MM-DD-<topic>.<ext>`, with the date the source was
  captured.
- Start each note with where the source came from (a URL or a document name)
  and the capture date.
- Files keep their original language; the notes you add are in English.
- The repository is public: nothing personal, private or secret.
- Link large or copyrighted documents instead of copying them.
- A source records a moment: do not edit it later. Add a newer dated file
  instead.
