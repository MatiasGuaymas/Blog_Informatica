# Blog Informática UNLP

A study companion for the four undergraduate programs of the Faculty of
Informatics at Universidad Nacional de La Plata (UNLP): APU, ATIC,
Licenciatura en Sistemas and Licenciatura en Informática.

- **Production:** <https://blog-informatica-mu.vercel.app>

## Quick start

```bash
pnpm install
pnpm dev   # http://localhost:3000
```

## Stack

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, shadcn/ui and
Base UI, deployed on Vercel.

## Language

The site content is written in Spanish for its audience. Everything else in
this repository (code, documentation, commits and pull requests) is written
in English.
